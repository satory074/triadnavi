# triadnavi — FF14 トリプルトライアド最善手ナビ

FF14 のミニゲーム「トリプルトライアド」で、対戦しながら次の一手を調べるための静的 Web アプリ。
その対戦で有効なルールとカードの四方向の数字を入れると、盤面を最後まで読み切って最善手を示します。

https://satory074.github.io/triadnavi/

## 機能

- 全ルール対応: セイム、プラス、コンボ、リバース、エースキラー、タイプアセンド/ディセンド、オーダー、カオス、サドンデス、オールオープン/スリーオープン
- 数字を 4 つ打つだけでカード名とタイプを自動判定(名前検索でも入力可)。自分のデッキは保存して再利用
- NPC を選ぶと、固定ルールと使用カードの候補(固定 + 可変)が自動で入る
- 結果に「確定」「保証」「推定」のラベルを付けて、どこまで信じてよいかを明示
  - 確定: 双方の手札が分かっている時。勝ち/引き分け/負けを厳密に判定
  - 保証: 相手の手札が裏向きでも、候補のどのカードを持っていても成り立つ結果
  - 推定: 候補も不明な手札、カオス。勝ちやすさの目安のみ
- 同点の手の中では「相手の応手のうち、何通りで自分の勝ちが確定するか」が多い手を優先
- 実機と計算が食い違った時のために、盤面の所有を手で直せる

デッキの力負けを覆すことはできません。勝てる局面を落とさないことと、相手のミスを最大限拾うことが目的です。

## 開発

```bash
npm install
npm run dev          # ローカル開発 (http://localhost:5173/triadnavi/)
npm test             # Vitest
npm run lint         # oxlint
npm run build        # 型チェック + 本番ビルド
npm run bench        # 探索のベンチマーク(空の盤面)
npm run data:update  # カード/NPC データの更新(手動。生成された JSON をコミットする)
```

## デプロイ

main への push で GitHub Actions が GitHub Pages に自動デプロイします。
